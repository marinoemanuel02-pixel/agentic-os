# Places Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One list of repos, vaults and folders (`config/places.json`) that `aos sync` registers as Paseo projects, plus a phone Inbox (panel capture, OneDrive share, and an inbox skill that files items only after the user's OK).

**Architecture:** aos (PowerShell) resolves the list, creates only the inbox folder, registers places with `paseo project create`, and writes the resolved list to `~\.aos\places.json`. The Paseo plugin in nar-tools reads that file and writes capture notes into the inbox through two new RPCs. A shared skill in `agents-home/skills/inbox` files the inbox with confirmation.

**Tech Stack:** PowerShell 5.1 + 7, Pester 5 (agentic-os); TypeScript, zod 4, vitest, React Native via `@getpaseo/plugin` 0.10.1 (nar-tools/paseo-plugin); Paseo CLI 0.10.1.

**Spec:** `docs/superpowers/specs/2026-09-29-places-design.md` (approved by the user on 2026-09-29).

## Global Constraints

- `aos.psm1` stays ASCII-only and runs under Windows PowerShell 5.1 and PowerShell 7: no `??`, no ternary, no `&&`/`||`. Run `aos test` after every edit.
- Tests use `$TestDrive`/`$caseRoot` and `$env:AOS_BACKUPS`; never the real profile, registry, network, Paseo or Desktop. The suite throws on any unmocked external command.
- Every step is idempotent: a second `aos sync` changes nothing. DryRun writes nothing and runs no Paseo command that changes state.
- The repo holds no absolute paths: `config/places.json` uses `{{desktop}}`, `{{projects}}`, `{{home}}`.
- The inbox is the only folder aos ever creates. Nothing is created for a missing place.
- Paseo CLI (checked live 2026-09-29): `paseo project ls --json` returns `[{"projectId","name","kind","path"}]`; `paseo project create "<path>"` registers a folder. Start the daemon only through the logon task (`Start-AosPaseoDaemon`).
- Panel input: `{ text: string (at most 100,000 characters), link?: http(s) URL (at most 2,048 characters) }`, strict, at least one non-empty. The phone never sends a path or a file name.
- Note name `YYYY-MM-DD HHmm <slug>.md` (local time); slug from letters, digits, spaces, `-`, `_`, at most 50 characters, never a Windows reserved name; clash -> ` (2)`, ` (3)`...; never an overwrite. UTF-8 without BOM.
- The inbox skill never moves, edits or deletes anything in a vault without the user's explicit confirmation, and logs each move to `Inbox\_filed.md`.
- New or changed behaviour gets a test; ideally the other vendor writes it (split authorship).

## Review Focus

- Paseo installed but its daemon stopped: `paseo project ls` fails; `aos sync` must warn once, still write `~\.aos\places.json`, and not abort the rest of the sync (Task 2 test "daemon down").
- A path Paseo already knows with a different case or a trailing backslash: must not register twice (Task 2 test "same folder, other spelling").
- A hand-edited `config/places.json` with an unknown kind, an unknown `{{placeholder}}`, a duplicate name, or zero/two inboxes: warn and skip the bad entry, never throw (Task 1 tests).
- A capture whose text is only emoji or punctuation, or a link with no text: the slug falls back (`note` / the link host), the file is still written (Task 4 tests).
- Two captures in the same minute with the same first words: ` (2)` suffix, and a concurrent write never overwrites (Task 4 test with a pre-existing file; `wx` flag).

```powershell
function Get-AosDesktopDir { return [Environment]::GetFolderPath('Desktop') }   # OneDrive-redirected on this PC

function Get-AosPlacesConfigPath { return (Join-Path $script:Root 'config\places.json') }

function Resolve-AosPlacePath([string]$Path) {
    # {{desktop}}, {{projects}}, {{home}}; $null for any other {{...}}.
    $map = @{ '{{desktop}}' = (Get-AosDesktopDir); '{{projects}}' = (Get-AosProjectsDir); '{{home}}' = $HOME }
    $out = $Path
    foreach ($k in $map.Keys) { $out = $out.Replace($k, [string]$map[$k]) }
    if ($out -match '\{\{[^}]*\}\}') { return $null }
    return [System.IO.Path]::GetFullPath($out)
}

function Get-AosPlaces {
    # The resolved places list; bad entries are skipped with a warning, never thrown.
    $cfgPath = Get-AosPlacesConfigPath
    if (-not (Test-Path -LiteralPath $cfgPath)) { return $null }
    $cfg = Read-AosJson $cfgPath
    $kinds = @('repo', 'vault', 'folder', 'inbox')
    $seen = @{}
    $inboxes = 0
    $out = New-Object 'System.Collections.Generic.List[object]'
    foreach ($p in @($cfg['places'])) {
        if (-not ($p -is [System.Collections.IDictionary])) { continue }
        $name = [string]$p['name']; $kind = [string]$p['kind']
        if ($kinds -notcontains $kind) { Write-AosWarn "place '$name': unknown kind '$kind' (skipped)"; continue }
        if ($seen.ContainsKey($name)) { Write-AosWarn "place '$name' is listed twice (second skipped)"; continue }
        $path = Resolve-AosPlacePath ([string]$p['path'])
        if (-not $path) { Write-AosWarn "place '$name': unknown placeholder in $($p['path']) (skipped)"; continue }
        if ($kind -eq 'inbox') {
            if ($inboxes -gt 0) { Write-AosWarn "place '$name': a second inbox (skipped; exactly one allowed)"; continue }
            $inboxes++
        }
        $seen[$name] = $true
        $out.Add([ordered]@{ name = $name; kind = $kind; path = $path; exists = (Test-Path -LiteralPath $path -PathType Container) })
    }
    if ($inboxes -eq 0) { Write-AosWarn 'config/places.json has no inbox place: phone capture has nowhere to write' }
    return $out.ToArray()
}
```

Note: `Read-AosJson` returns hashtables via `ConvertTo-AosHashtable`; if `@($cfg['places'])` wraps the list in another list under 5.1 (see Traps: "`@(ConvertTo-AosHashtable ...)` wraps a JSON list in another list"), iterate `$cfg['places']` without `@()` and test under both shells.

```powershell
function Get-AosPaseoProjectPaths {
    # Folders Paseo already knows, normalized for comparison; $null when Paseo cannot answer.
    $r = Invoke-AosCapture 'paseo project ls --json'
    if ($r.Code -ne 0) { return $null }
    $out = New-Object 'System.Collections.Generic.List[string]'
    # No @(): ConvertTo-AosHashtable returns the list whole (5.1 and 7 unroll differently).
    foreach ($p in (ConvertTo-AosHashtable (ConvertFrom-Json -InputObject $r.Text))) {
        if ($p -is [System.Collections.IDictionary] -and $p['path']) { $out.Add(([string]$p['path']).TrimEnd('\').ToLowerInvariant()) }
    }
    return ,$out.ToArray()
}

function Sync-AosPlaces([switch]$DryRun) {
    # Creates only the inbox; registers existing places in Paseo; writes ~\.aos\places.json for the
    # plugin and the inbox skill. A missing place is warned about, never created.
    $places = Get-AosPlaces
    if ($null -eq $places) { Write-AosInfo 'no config/places.json: places skipped'; return }
    foreach ($p in $places) {
        if ($p['exists']) { continue }
        if ($p['kind'] -ne 'inbox') { Write-AosWarn "place '$($p['name'])' is missing: $($p['path'])"; continue }
        if ($DryRun) { Write-AosDry "would create the inbox $($p['path'])"; continue }
        New-Item -ItemType Directory -Force -Path $p['path'] -ErrorAction Stop | Out-Null
        $p['exists'] = $true
        Write-AosOk "created the inbox $($p['path'])"
    }
    if (-not (Test-AosCommand paseo)) { Write-AosInfo 'paseo is not installed: places not registered (aos install phone)' }
    else {
        $known = Get-AosPaseoProjectPaths
        if ($null -eq $known) { Write-AosWarn 'paseo project ls failed (is the daemon running? aos install phone): places not registered' }
        else {
            foreach ($p in $places) {
                if (-not $p['exists']) { continue }
                if ($known -contains ([string]$p['path']).TrimEnd('\').ToLowerInvariant()) { Write-AosOk "Paseo knows $($p['name'])"; continue }
                if ($DryRun) { Write-AosDry "paseo project create `"$($p['path'])`""; continue }
                $c = Invoke-AosCapture "paseo project create `"$($p['path'])`""
                if ($c.Code -eq 0) { Write-AosOk "Paseo project $($p['name'])" }
                else { Write-AosWarn "paseo project create failed for $($p['name']) (exit $($c.Code))" }
            }
        }
    }
    $target = Join-Path (Get-AosStateDir) 'places.json'
    $want = [ordered]@{ places = @($places) }
    $a = ''
    $have = Read-AosJson $target
    if ($have) { $a = ConvertTo-Json -InputObject $have -Depth 5 -Compress }
    $b = ConvertTo-Json -InputObject (ConvertTo-AosHashtable (ConvertFrom-Json -InputObject (ConvertTo-Json -InputObject $want -Depth 5))) -Depth 5 -Compress
    if ($a -ceq $b) { Write-AosOk "$target up to date"; return }
    if ($DryRun) { Write-AosDry "would write $target"; return }
    Write-AosText -Path $target -Text ((ConvertTo-Json -InputObject $want -Depth 5) + "`n")
    Write-AosOk "wrote $target"
}
```

    if (Test-Path -LiteralPath (Join-Path $FullPath '.git')) { return 'repo' }
    if (Test-Path -LiteralPath (Join-Path $FullPath '.obsidian')) { return 'vault' }
    return 'folder'

function ConvertTo-AosPlacePath([string]$FullPath) {
    # Longest root first ({{projects}} lives inside {{desktop}}); $null outside the home folder.
    $full = [System.IO.Path]::GetFullPath($FullPath).TrimEnd('\')
    foreach ($pair in @(@('{{projects}}', (Get-AosProjectsDir)), @('{{desktop}}', (Get-AosDesktopDir)), @('{{home}}', $HOME))) {
        $root = ([string]$pair[1]).TrimEnd('\')
        if ($full.StartsWith($root + '\', [System.StringComparison]::OrdinalIgnoreCase)) { return $pair[0] + $full.Substring($root.Length) }
    }
    return $null

function Add-AosPlace([string]$Path, [string]$Name, [string]$Kind) {
    # Appends to config/places.json (the user commits it), then syncs. $true when added.
    if (-not $Path) { Write-AosWarn 'usage: aos place add <folder> [--name <n>] [--kind repo|vault|folder]'; return $false }
    $full = [System.IO.Path]::GetFullPath($Path)
    if (-not (Test-Path -LiteralPath $full -PathType Container)) { Write-AosWarn "no folder at $full"; return $false }
    if (-not $Kind) { $Kind = Get-AosPlaceKind $full }
    if (@('repo', 'vault', 'folder') -notcontains $Kind) { Write-AosWarn "kind must be repo, vault or folder (the inbox is set in config/places.json)"; return $false }
    if (-not $Name) { $Name = Split-Path -Leaf $full }

    foreach ($p in @($cfg['places'])) {

import type { RpcOutput } from "@getpaseo/plugin";
import { existsSync, readdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { inboxRecentRpc, inboxSaveInput, inboxSaveRpc } from "../shared/rpc";

const RESERVED = /^(con|prn|aux|nul|com[1-9]|lpt[1-9])$/i;
const pad = (n: number) => String(n).padStart(2, "0");

function clean(s: string): string {
  return s.replace(/[^\p{L}\p{N} _-]+/gu, " ").replace(/\s+/g, " ").trim();
}

// The first words of the text, else the link's host; letters, digits, spaces, - and _ only.
export function slugFor(text: string, link?: string): string {
  let slug = clean(text.trim().split(/\r?\n/)[0] ?? "");
  if (!slug && link) slug = clean(new URL(link).hostname.replace(/^www\./, "").replace(/\./g, "-"));
  slug = Array.from(slug).slice(0, 50).join("").trim();
  if (!slug) slug = "note";
  if (RESERVED.test(slug)) slug = `${slug}_`;
  return slug;
}

function localStamp(d: Date): string {
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())} ${pad(d.getHours())}${pad(d.getMinutes())}`;
}

function localIso(d: Date): string {
  const off = -d.getTimezoneOffset();
  const a = Math.abs(off);
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}:` +
    `${pad(d.getSeconds())}${off >= 0 ? "+" : "-"}${pad(Math.floor(a / 60))}:${pad(a % 60)}`;
}

function noteContent(d: Date, text: string, link?: string): string {
  const lines = ["---", `captured: ${localIso(d)}`, "source: phone", `type: ${link ? "link" : "note"}`];
  if (link) lines.push(`link: ${JSON.stringify(link)}`);
  lines.push("---", text);
  return lines.join("\n") + "\n";
}

// The inbox path from ~/.aos/places.json (written by aos sync). Never creates anything.
function inboxDir(home: string): string {
  const file = join(home, ".aos", "places.json");
  if (!existsSync(file)) throw new Error("~/.aos/places.json not found: run aos sync on the PC");
  const places: unknown = JSON.parse(readFileSync(file, "utf8").replace(/^\uFEFF/, "")).places;
  const inbox = Array.isArray(places)
    ? places.find((p): p is { path: string } => typeof p === "object" && p !== null && p.kind === "inbox" && typeof p.path === "string")
    : undefined;
  if (!inbox) throw new Error("no inbox in ~/.aos/places.json: check config/places.json, then run aos sync");
  if (!existsSync(inbox.path) || !statSync(inbox.path).isDirectory()) throw new Error(`the inbox folder ${inbox.path} is missing: run aos sync`);
  return inbox.path;
}

function saveNote(dir: string, d: Date, text: string, link?: string): string {
  const base = `${localStamp(d)} ${slugFor(text, link)}`;
  const content = noteContent(d, text, link);
  for (let n = 1; n < 1000; n++) {
    const name = n === 1 ? `${base}.md` : `${base} (${n}).md`;
    try {
      writeFileSync(join(dir, name), content, { encoding: "utf8", flag: "wx" }); // wx: fail if it exists
      return name;
    } catch (error) {
      if ((error as NodeJS.ErrnoException).code !== "EEXIST") throw error;
    }
  }
  throw new Error("too many notes with the same name in one minute");
}

function capturedOf(file: string): string | null {
  const head = readFileSync(file, "utf8").slice(0, 1000);
  if (!head.startsWith("---")) return null;
  return /^captured: (.+)$/m.exec(head)?.[1]?.trim() ?? null;
}

function recentNotes(dir: string, limit = 10) {
  return readdirSync(dir, { withFileTypes: true })
    .filter((e) => e.isFile() && e.name.toLowerCase().endsWith(".md") && e.name !== "_filed.md")
    .map((e) => ({ name: e.name, mtime: statSync(join(dir, e.name)).mtimeMs }))
    .sort((a, b) => b.mtime - a.mtime)
    .slice(0, limit)
    .map(({ name }) => ({ name, captured: capturedOf(join(dir, name)) }));
}

const message = (error: unknown) => (error instanceof Error ? error.message : String(error));

export function createInboxHandlers(home: string, now: () => Date = () => new Date()) {
  return {
    async inboxSave(input: unknown): Promise<RpcOutput<typeof inboxSaveRpc>> {
      const parsed = inboxSaveInput.safeParse(input);
      if (!parsed.success) return { ok: false, error: "invalid input" };
      try {
        return { ok: true, name: saveNote(inboxDir(home), now(), parsed.data.text, parsed.data.link) };
      } catch (error) { return { ok: false, error: message(error) }; }
    },
    async inboxRecent(input: unknown): Promise<RpcOutput<typeof inboxRecentRpc>> {
      if (!inboxRecentRpc.input.safeParse(input).success) return { ok: false, error: "invalid input" };
      try { return { ok: true, items: recentNotes(inboxDir(home)) }; }
      catch (error) { return { ok: false, error: message(error) }; }
    },
  };
}

- [ ] **Step 1: Create `client/inbox.tsx`**

```tsx
import { type PluginWorkspacePanelProps, useRpc } from "@getpaseo/plugin/client";
import { useQuery } from "@tanstack/react-query";
import { useRef, useState } from "react";
import { Pressable, StyleSheet, Text, TextInput, View } from "react-native";
import { inboxRecentRpc, inboxSaveRpc } from "../shared/rpc";

export function InboxSection({ theme, hostId }: { theme: PluginWorkspacePanelProps["theme"]; hostId: string }) {
  const callSave = useRpc(inboxSaveRpc);
  const callRecent = useRpc(inboxRecentRpc);
  const recent = useQuery({ retry: false, refetchOnWindowFocus: false, queryKey: ["aos", hostId, "inbox"], queryFn: () => callRecent({}) });
  const [text, setText] = useState("");
  const [link, setLink] = useState("");
  const [message, setMessage] = useState<{ ok: boolean; text: string }>();
  const saving = useRef(false);
  const [pending, setPending] = useState(false);
  const empty = text.trim() === "" && link.trim() === "";

  async function save() {
    if (saving.current || empty) return;
    saving.current = true;
    setPending(true);
    setMessage(undefined);
    try {
      // One RPC, never retried: a retry after a lost reply could save the note twice.
      const result = await callSave({ text, ...(link.trim() ? { link: link.trim() } : {}) });
      if (result.ok) { setText(""); setLink(""); setMessage({ ok: true, text: `Saved: ${result.name}` }); }
      else setMessage({ ok: false, text: `Not saved: ${result.error}` });
    } catch (error) {
      // The text stays in the box. The PC may still have saved it: the list below shows what landed.
      setMessage({ ok: false, text: `No answer from the PC (${error instanceof Error ? error.message : String(error)}). Your text is kept; check the list before saving again.` });
    } finally {
      saving.current = false;
      setPending(false);
      void recent.refetch();
    }
  }

  const styles = StyleSheet.create({
    section: { gap: 12 },
    heading: { color: theme.colors.foreground, fontSize: 20, fontWeight: "600" },
    input: { backgroundColor: theme.colors.surface1, color: theme.colors.foreground, padding: 12, borderRadius: 8 },
    multi: { minHeight: 96, textAlignVertical: "top" },
    text: { color: theme.colors.foreground },
    muted: { color: theme.colors.foregroundMuted },
    error: { color: theme.colors.statusDanger },
    card: { backgroundColor: theme.colors.surface1, padding: 16, borderRadius: 8, gap: 8 },
    button: { backgroundColor: theme.colors.accent, padding: 12, borderRadius: 8 },
    buttonText: { color: theme.colors.accentForeground },
    disabled: { opacity: 0.5 },
  });

  let list;
  if (recent.isPending) list = <Text style={styles.muted}>Loading...</Text>;
  else if (recent.error) list = <Text style={styles.error}>{String(recent.error)}</Text>;
  else if (!recent.data.ok) list = <Text style={styles.error}>{recent.data.error}</Text>;
  else if (recent.data.items.length === 0) list = <Text style={styles.muted}>The inbox is empty.</Text>;
  else list = recent.data.items.map((item) => <Text key={item.name} style={styles.text}>{item.name}</Text>);

  return (
    <View style={styles.section}>
      <Text style={styles.heading}>Inbox</Text>
      <TextInput style={[styles.input, styles.multi]} multiline value={text} onChangeText={setText} maxLength={100_000}
        placeholder="A thought or a note (the keyboard's mic dictates)" placeholderTextColor={theme.colors.foregroundMuted}
        accessibilityLabel="Inbox note" />
      <TextInput style={styles.input} value={link} onChangeText={setLink} maxLength={2048} placeholder="Link (optional)"
        placeholderTextColor={theme.colors.foregroundMuted} autoCapitalize="none" autoCorrect={false} keyboardType="url"
        accessibilityLabel="Inbox link" />
      <Pressable accessibilityRole="button" accessibilityLabel="Save to inbox" accessibilityState={{ disabled: pending || empty }}
        disabled={pending || empty} onPress={() => void save()} style={[styles.button, (pending || empty) && styles.disabled]}>
        <Text style={styles.buttonText}>{pending ? "Saving..." : "Save"}</Text>
      </Pressable>
      {message ? <Text style={message.ok ? styles.muted : styles.error}>{message.text}</Text> : null}
      <View style={styles.card}>{list}</View>
    </View>
  );
}
```

In `client/panel.tsx`: add `import { InboxSection } from "./inbox";` and render `<InboxSection theme={theme} hostId={host.id} />` as the FIRST child of the scroll view's content (capture is the most frequent action).
