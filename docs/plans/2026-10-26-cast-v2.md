# Cast v2: characters that pass the director, and a pipeline that makes them repeatably

Status: plan for review, nothing implemented. Written 2026-10-26 after the director rejected the v10 cast ("ancora
assolutamente no sui personaggi, sono veramente low quality"), the fourth rejected iteration (v8, v9, v10 and the
v10 kit). Inputs: two deep-research reports (`docs/research/2026-10-26-cast-deep-research-chatgpt.md`,
`...-perplexity.md`), the Codex research spec (pauseai-it `research/character-spec-codex-2026-10-26.md`), and this
session's own record of why four iterations failed. The reports are material, not authority: where this plan departs
from them it says why.

## 1. Why four iterations failed (our diagnosis, beyond the reports)

1. **The visible art was generated, not designed.** Every version computed contours from a skeleton and parameters,
   then added finish (cel shadow, rim, grain, outlines). Both reports reach the same verdict from studio practice:
   design order is idea, gesture, silhouette, shapes, construction, face and hands, colour, line, light, texture. Ours
   ran the other way. More parameters made a more sophisticated generic body.
2. **Our quality gate measured the wrong thing.** Codex and I compared each version with the previous one ("v10 is a
   large improvement over v9") and said YES while the director said no. Relative improvement over our own baseline
   is not the target; the target is studio work at the same screen size. No gate ever put our frame next to a
   reference frame.
3. **No art direction document existed.** No style charter, model sheet, or list of forbidden results ("no-no
   sheet"): every iteration re-decided taste inside code, and agents converge on valid-but-generic shapes.
4. **Acting was an afterthought.** Poses were joint angles chosen per shot; neutral poses were symmetric; hands were
   symbols; the face was assembled from independent symbols (eyes, lids, mouth).
5. **Characters were small in frame** in most shots, so even the improvements did not reach the viewer.

The rig code is not the problem and stays: it becomes the skeleton under authored art.

## 2. Target architecture

Rule (from the ChatGPT report, adopted): **proceduralize repetition, not taste.** Code poses, swaps, times, recolours
and checks authored drawings; it does not invent the visible shapes of lead characters.

```text
templates/video/src/lib/cast/
  art/<character>/          authored SVG masters (named groups), replacement drawings, per view
    body-front.svg body-3q.svg head-front.svg head-3q.svg head-profile.svg
    hands.svg               12-16 authored hand drawings, left and right checked, not mirrored blindly
    feet.svg                planted 3/4, planted profile, heel up, toe up, front
    forearms.svg            normal, compressed, foreshortened (replacement, not deformation)
    expressions.svg         8 expressions (eyes, lids, brows, mouth corners, head attitude)
    mouths.svg              visemes drawn inside at least two expressions
  rig/<character>.rig.json  pivots, z-order options, grip anchors, limits (extracted from markers in the SVG)
  poses/<character>/*.json  12 authored storytelling poses (meaning, line of action, weight leg, counterpose)
  Character.tsx             renders a view + pose + expression + viseme + hands + props
  geom.ts                   today's skeleton maths: kept for anchors, IK, interpolation, crowds
  checks/                   silhouette, grayscale, thumbnail, no-effects, tangency, anchor drift
```

- **Views, not rotation:** front, 3/4 and profile are separate drawings; the 3/4 turn of today's kit is retired for
  leads.
- **Face layering:** final face = identity + expression + viseme + blink/gaze; the expression changes the viseme
  ("A" while worried is not "A" while calm).
- **Light belongs to the scene:** `scene.light` (direction, key, ambient, rim strength) drives shading; no
  per-character rim colour. Review renders start flat; rim and grain come back only after the shapes pass.
- **Today's procedural `Person`** stays for crowds, far background people and previz, under its current tests.
- **API for shots:** `<Character who view pose expression gaze handL handR speech props/>`, where `pose` names an
  authored performance setup, not 13 joint angles.

## 3. The decision this plan cannot make: who draws the visible art

Everything above needs authored drawings. The candidates, with what each costs:

| Source | Ceiling | Cost and risk |
|---|---|---|
| **A. The operator (or someone the operator chooses) draws the masters** in Inkscape or Krita (both installed) | highest; real identity | operator time; a commission costs money (needs an explicit OK and a cap) |
| **B. CC0 human-made libraries restyled:** Open Peeps ("Free for commercial and personal use under CC0 License", checked 2026-10-26) or Humaaans (CC0, checked) | professional shapes immediately | can read as stock; their style (Open Peeps' line, Humaaans' editorial flat) must fit or be restyled without losing what makes it work |
| **C. Agents author the SVG masters by hand** (path by path, against a charter and references, blind-judged) | unknown; this is closest to what failed | cheapest in operator time; only acceptable if it wins the experiment below |
| **D. Hybrid:** B to bootstrap and for extras, A or C for one gold lead | high | two styles must be unified by the charter |

The plan does not guess. **Gate 0 is an experiment that lets the director choose with stills** (section 4).

## 4. Phases and gates

Every gate ends with a decision sheet the director can judge in minutes. No phase starts code before the gate before it
passes. Estimates are elapsed agent time, not promises.

**G0. Calibrate taste and choose the art source (1-2 days).**
- Build a *taste sheet*: about 16 tiles at matched size, unlabelled and shuffled. It mixes reference frames from the
  target studios (Rational Animations, Kurzgesagt, Duolingo, Headspace, TED-Ed; screenshots for internal comparison
  only, never in a film), our v10 cast, and candidates for B and C (one character each, same pose, same background).
- The director marks each tile acceptable or not and names the best three. That anchors the rubric to the director's
  eye instead of ours, and picks A, B, C or D.
- Also asked here: the three reference frames the director most wants the cast to feel like.

**G1. Style charter, no-no sheet, reference board (1-2 days).**
- 24-30 references in three groups: finished shots, construction (model sheets, hand and expression sheets), acting
  (people explaining, listening, objecting, holding phones and cards). Kept as a private board, with sources.
- One-page charter: heads, limbs, hands, feet, face, line hierarchy (silhouette heavier than internals, ratios in the
  ChatGPT report as a starting point), light, texture, posing.
- A no-no sheet drawn from our own rejected frames: what agents must never normalise (equal limb widths, symmetric
  neutral, tangencies, sticker rims, emoji faces, tiny hands, floating feet).

**G2. One gold character, still only (3-4 days).**
- 20 silhouette variants in black, then 3 in the real rejected shot's background, then 1.
- Then front, 3/4, profile, back; 8 expressions; 12-16 hands; 5 feet; 8-12 acting poses: the model sheet.
- No rig code during this phase. Gate: the director approves the gold character still, at the film's real screen
  size, next to the references from G0. If the still fails, nothing gets rigged.

**G3. Layered masters and the rig (3-4 days).**
- The approved drawings become layered SVG with named groups and pivot markers (no destructive optimizer).
- Agents build: importer and layer validation, pivot extraction to rig JSON, view and replacement swaps, hand and
  prop contract, face layering, pose serialization, a Studio pose browser.
- Agents never redraw approved contours.
- Gate: the rig reproduces the model-sheet poses with no visible difference (pixel diff against the masters).

**G4. Performance and the decisive shot (2-3 days).**
- 12 authored poses with silhouette thumbnails.
- The facial test: three lines (calm, emphatic, worried) with identical phonemes must look different.
- Then rebuild one rejected shot three ways: A (v10), B (new flat, no rim or grain), C (new, lit and textured).
- Gate: the director judges A against B. If B is not clearly professional, the design failed, whatever C looks like.

**G5. The cast (3-5 days).**
- Other leads are derived from the gold character's grammar, changing at least four primary silhouette variables each
  (head mass, shoulder-to-hip, torso, limb rhythm, hand size, stance, hair mass, costume outline), not just recolours.
- Background people stay procedural.
- Gate: the lineup in black silhouette is identifiable per character.

**G6. Pipeline integration.**
- The template carries the system (art folder contract, rig, checks, sheets).
- `video-rules.md` gets the rules this plan earned (an authored-art rule for leads; a gate that compares with
  references, never only with the last version).
- `frontier.md` is rewritten, with a dated decision.
- pauseai-it gets a v11 with the new cast, staged larger in frame.

## 5. Quality gate (replaces "better than last time")

- **Automated checks**, rendered on every asset change:
  - silhouette (black fill) lineup;
  - grayscale;
  - smallest-delivery-size thumbnail;
  - no-effects (no rim, grain or cel);
  - tangency warnings between parts;
  - anchor drift between poses;
  - missing layers.
  These are kill tests: a failure stops polishing.
- **Rubric:** the ChatGPT report's 100-point rubric, with weights re-anchored by the G0 taste sheet. Ship at 85, and
  no category below 70 % of its points.
- **Reviews, kept separate:**
  - Codex judges blind, pairwise, our frame against a reference frame at the same size. The question is "which is
    professional explainer quality, and why", never "is this better than v10".
  - Claude judges the same way.
  - The director's verdict is the gate. A reviewer's YES does not pass a gate the director has not seen.
- **Same-size rule:** every judgement uses the real film scale plus one close-up, never a close-up alone.

## 6. Tools and what each changes

| Tool | Role | Effect on the approach |
|---|---|---|
| Inkscape (installed) | authoring and cleaning layered SVG masters; scripted export of named groups | the art lives as editable SVG that both a person and code can read |
| Krita (installed) | rough silhouette and pose exploration, drawn options for A | fast loose drawing before vectors; never shipped directly |
| Penpot (local MCP, `penpot-local`) | alternative SVG authoring with components | optional; useful if agents need structured component editing |
| Remotion | sheets, checks, the pose browser, the film | unchanged runtime; Studio can expose SVG for visual tweaks |
| Blender + Grease Pencil (installed) | later: hand-animated hero inserts only | not the main pipeline (shot-by-shot, weak parametric control) |
| Open Peeps / Humaaans (CC0, checked) | option B source, crowd and extra bootstrap | licence-clean starting shapes; style risk handled by the charter |
| Rive, Spine | excluded | Rive free export plays a Rive splash screen (pricing page, checked); Spine authoring is commercial |
| Lottie | optional, authored loops only | playback format, not the acting rig |
| Codex | blind pairwise reviews; independent second author for option C candidates; writes failing tests for the checks | independence where Claude judged its own work too kindly |
| Claude | charter, rig, importer, checks, integration; candidate author for C | builder and integrator, not the taste gate |
| Local model / pool | sort and tag reference images, check licences, summarise sources | keeps cloud tokens for judgement |

## 8. Open questions for the operator (blocking G0)

1. Art source: who is allowed to draw the visible art? A (the operator, or a person the operator names), B (CC0
   libraries restyled), C (agents), D (hybrid). The default if no answer: run the G0 experiment with B and C only,
   since A needs the operator's time.
2. Is a paid commission thinkable at all (it would break the free-stack rule)? Default: no.
3. Which three reference frames should the cast feel like? (G0 asks this anyway.)
4. How many lead characters must the next film have? Fewer leads means faster gates.

## 9. Risks

- **Stock look (B):** handled by the charter and the G0 taste sheet. If the director rejects restyled libraries too,
  A is the remaining route.
- **C repeats the failure:** C must win blind at G0 against B before anyone builds on it.
- **Scope creep:** one gold character to G4 before any second lead.
- **Reviewer drift:** a gate passes only with a reference frame next to ours, and only with the director.
